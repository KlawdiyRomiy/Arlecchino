New

- Added a related-file fallback when a direct definition cannot be resolved in the editor.
- Added shared project bootstrap state for the IDE, terminal, and MCP workflows.

Improved

- Fixed an idle editor reconfiguration loop that could cause unnecessary background work.

Compatibility

- Arlecchino advances to the `0.2.34-beta` version line for this build.
- The normal updater is tokenless and reads the beta manifest from GitHub Releases. Existing alpha updater clients can still move to this beta through the legacy alpha-channel manifest asset.
- Dependencies were refreshed, including Wails `v3.0.0-beta.4`. Vite is held at `8.1.5` because `8.2.1` stalls the production build in the current Rolldown toolchain. TypeScript 7 remains excluded, and xterm 6 remains held because the maintained canvas addon still requires xterm 5.
- ONNX Runtime is locked to `1.28.0` for `github.com/yalue/onnxruntime_go v1.32.0`; universal macOS preflight validates both `arm64` and `x86_64` runtime coverage before release.
- Wails is an upstream prerelease dependency; Arlecchino itself remains a beta product.

Release security

- Update manifests require SHA256 and Ed25519 verification before an update can be staged.
- macOS beta artifacts use the local certificate identity for owner/tester update stability. They are not Apple Developer ID signed or notarized, so Gatekeeper can still require a manual override.
