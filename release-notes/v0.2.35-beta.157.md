Changed

- The project README now opens with a workbench screenshot showing Explorer, editor, Git, and AI Chat side by side.
- The demo page loads faster: every demo video now has a poster image and defers its own download until playback starts.
- Published the MCP agent adapter JSON Schema next to the adapter loader, so external agents can validate an adapter config against the same contract the IDE reads.
- Refreshed the repository agent policy that ships with the source tree.

Compatibility

- Arlecchino advances to the `0.2.35-beta` version line for this build.
- The normal updater is tokenless and reads the beta manifest from GitHub Releases. Existing alpha updater clients can still move to this beta through the legacy alpha-channel manifest asset.
- Dependencies were refreshed, including Wails `v3.0.0-beta.9`. Vite is held at `8.1.5` because `8.2.1` stalls the production build in the current Rolldown toolchain. TypeScript 7 remains excluded because no released `typescript-eslint` supports it, and xterm 6 remains held as a deferred major upgrade.
- ONNX Runtime stays locked to `1.28.0` for `github.com/yalue/onnxruntime_go v1.32.0`; the newer binding would require ONNX Runtime `1.29.0`, so the runtime pair is upgraded on its own change rather than inside this release. Universal macOS preflight validates both `arm64` and `x86_64` runtime coverage before release.
- Wails is an upstream prerelease dependency; Arlecchino itself remains a beta product.

Release security

- Update manifests require SHA256 and Ed25519 verification before an update can be staged.
- macOS beta artifacts use the local certificate identity for owner/tester update stability. They are not Apple Developer ID signed or notarized, so Gatekeeper can still require a manual override.
